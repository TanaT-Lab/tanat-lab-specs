# tanat-demo - sub-repo spec

> Spec of the **TanaT demos**: narrated, interactive walkthroughs of TanaT
> served as a static site. The detailed working roadmap is `TODO.md` in the
> code repo; tasks will be derived from it into `tasks/`.

## Purpose / role in the ecosystem

Public showcase of TanaT, primarily for **conference talks**: a player types
real TanaT code step by step, shows its outputs and figures, synchronized with
an audio narration.

## Goal

1. Work with the current TanaT release (0.10.4).
2. Simplify the structure while keeping the existing UX (no redesign).
3. Each demo lasts **less than 5 minutes**.
4. Scale to several demos; move to `github.com/TanaT-Lab/tanat-demo`.

## Scope

- **In scope:** demo content (pipeline code, data, narration, audio), the
  static player and landing page, output generation, CI and Pages deployment.
- **Out of scope:** TanaT features themselves (`tanat`), dataset generation
  (`tanat-synthea`).

## Decisions (2026-10-26)

| Topic | Decision |
|---|---|
| Content | Aligned on the TanaT MIMIC tutorials (`doc/source/user-guide/tutorials/mimic/`), no extra steps. |
| Single source of code | One `pipeline.py` per demo, split into `# %% <id>` blocks. A generic generator runs it and writes `outputs.json` (code, output, figure per block), the only source read by the player. |
| Data | CSV versioned in `data/`, loaded with `pd.read_csv` (no network at a conference). `data/build_csv.py` rebuilds it from `tanat.dataset.access('mimic4')`. |
| TanaT version | Pinned: `tanat==0.10.4` (PyPI). |
| Audio | Generated by script from `SCRIPT.md` split into sections; local CPU TTS (Kokoro-82M, pending a listening POC); mp3 versioned, regenerated only when text changes. |
| Duration | Audio budget about 4 min 20 (currently 5 min 38); build fails above 4 min 45. |

## Interfaces with other sub-repos

- **Depends on** `tanat` via PyPI (pinned). The pipeline code must follow the
  current public API; the MIMIC tutorials in `tanat` are the reference.
